# Карта взаимосвязей переменных

Интерактивная сеть: узлы — переменные набора, линии — статистические связи.
Карта показывает **связи**, а не причинно-следственные зависимости.

## Что считается

| Пара переменных | Метод | Что показывает |
|---|---|---|
| количественная + количественная | Pearson / Spearman / Kendall (по выбору) | направление и силу монотонной/линейной связи |
| категориальная + категориальная | V Крамера, χ² | силу связи без направления |
| количественная + категориальная | η² (корреляционное отношение), ANOVA | долю дисперсии, объяснённую группами; без направления |

- Пропуски исключаются попарно, поэтому N зависит от пары.
- p-value считается для каждой пары; q-value — поправка Benjamini–Hochberg
  на множественные сравнения. Фильтр «только значимые» использует q < 0,05.
- «Авто» выбирает Pearson для двух количественных шкал и Spearman, если есть
  порядковая переменная.
- Сильные корреляции — повод проверить VIF/мультиколлинеарность, а не готовый
  вывод о причинности.

## Интерфейс

Раздел **«Карта связей»** в боковом меню.

- фильтр по силе связи, направлению и значимости;
- выбор метода;
- поиск и подсветка переменной;
- скрытие/показ групп: количественные, порядковые, категориальные;
- клик по переменной — тип, уровень, N, пропуски, уникальные значения,
  рекомендации, доступные методы анализа и список связей;
- клик по линии — метод, статистика, p, q, N, направление, предупреждения;
- кнопка «Обновить»; карта также проверяет `dataset_revision` при возврате
  фокуса и раз в несколько секунд, поэтому после правок данных пересобирается
  автоматически;
- сводка: сильнейшие связи, потенциальная мультиколлинеарность, переменные
  с наибольшим числом значимых связей.

## API

`POST /api/datasets/{dataset_id}/relationships`

```json
{
  "method": "auto",
  "max_variables": 60
}
```

Ответ:

```json
{
  "dataset_revision": "...",
  "nodes": [],
  "edges": [],
  "summary": {
    "n_nodes": 14,
    "n_edges": 91,
    "n_significant": 9,
    "n_potential_collinearity": 0,
    "strongest": [],
    "most_connected": [],
    "recommendations": []
  },
  "methodology": {}
}
```

Ошибка метода — 422; чужой набор — 404.

`GET /api/datasets/{id}/revision` — версия файла для автоматического обновления
карты после правок.

## Ограничения

- Только парные связи; условные и множественные зависимости не показаны.
- V Крамера и η² не имеют направления; линии для них нейтральные.
- При большом числе переменных показываются первые `max_variables` (по умолчанию
  60); это отмечается в сводке.
- Переменные с большим числом уникальных категорий и константы не участвуют
  в связях, но остаются узлами с пояснением.
- Карта не заменяет корреляционную матрицу, регрессию и содержательную теорию.
