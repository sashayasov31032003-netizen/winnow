# Происхождение проекта: что своё, что чужое и почему это законно

Документ отвечает на вопрос «а это не копия?» — для диплома, разговора с
заказчиком или юристом. Здесь перечислено, что написано для проекта, какие
источники использовались, чего сознательно не делали и какие лицензии
действуют. Это не юридическая консультация: перед коммерческим запуском
покажите проект юристу по интеллектуальному праву.

## Коротко

**Winnow — независимая реализация статистического пакета.** Проект не связан с
IBM и SPSS, не является их форком, не использует их код, иконки, тексты и
данные. Весь код в `src/winnow`, `web/`, `tests/` написан для этого проекта.
Сторонние компоненты — только библиотеки из списка ниже, под разрешительными
лицензиями, и ни одна из них не связана с SPSS.

Это законно по той же причине, по которой существуют LibreOffice рядом с MS
Office, GIMP рядом с Photoshop, а PSPP, JASP и jamovi — рядом со SPSS:
функциональность, методы и идеи не защищены авторским правом, защищены
конкретный код, тексты, оформление и товарные знаки.

## Источники знаний (не кода)

- **Статистические методы** — учебники и статьи: t-критерий, ANOVA,
  хи-квадрат, корреляции, регрессия, факторный анализ, надёжность. Формулы
  реализованы самостоятельно, без переноса чужого кода.
- **Проверка чисел** — три независимых способа: ручной расчёт по формулам,
  сверка с `scipy` и эталонные значения из литературы или вывода SPSS.
  Эталоны для взвешенных процедур — в `docs/weights-reference.md`; там
  приведены только числа (факты), сам файл вывода SPSS в репозиторий не входит.
- **Формат `.sav`** — по открытому описанию структуры файла (заголовок, записи
  переменных, метки, расширения). PSPP и SPSS упоминаются как описание формата
  и эталон результатов; их исходный код в проект не переносился.
- **Синтаксис `.sps`** — по описанию команд SPSS; разбор написан свой.
- **Названия процедур и пунктов меню** — общеупотребительные статистические
  термины («Частоты», «Таблицы сопряжённости», «Линейная регрессия»); они не
  являются товарными знаками.

## Чего сознательно не делали

- в проекте нет чужого исходного кода: ни скопированного, ни полученного
  декомпиляцией;
- не включали код под GPL: `pingouin` (GPL-3) не используется, `pyreadstat` /
  ReadStat (часть кода выросла из GPL-проекта PSPP) не используется — вместо
  него свой парсер `.sav`;
- не брали чужие наборы данных, скриншоты, иконки, шаблоны интерфейса и
  тексты документации. Скриншоты в `docs/screenshots/` — снимки **этого**
  приложения (старая версия оформления, до переименования и редизайна);
- не используем в названии, логотипе и оформлении товарные знаки IBM и SPSS;
- не заявляем партнёрство с IBM и «полную совместимость» там, где её нет.
  Формулировка «в духе SPSS» — сравнение, а не указание на происхождение.

## Сторонние компоненты и лицензии

Движок и веб-версия: только разрешительные лицензии, копилефт-кода нет.

| Компонент | Лицензия | Что это значит |
|---|---|---|
| numpy, pandas, scipy | BSD-3-Clause | можно использовать в закрытом продукте |
| PySide6 (Qt) | LGPL-3.0 (или GPL) | можно оставить свой код закрытым, но нужно выполнить условия LGPL |
| python-docx, openpyxl | MIT | безопасно |
| FastAPI, SQLAlchemy, pydantic | MIT | безопасно |
| uvicorn, starlette, httpx | BSD-3-Clause | безопасно |
| python-multipart | Apache-2.0 | безопасно |
| email-validator | Unlicense | общественное достояние |
| pytest (тесты) | MIT | безопасно |
| React, react-dom, Vite, oxlint | MIT | безопасно |
| TypeScript | Apache-2.0 | безопасно |

**Про LGPL и PySide6.** Для закрытой коммерческой настольной сборки нужно
соблюсти LGPL: динамическая компоновка, уведомление о лицензии и возможность
заменить библиотеку своей версией. Схему сборки стоит согласовать с юристом;
веб-версия Qt не использует вовсе.

**Чего нет в зависимостях:** `pingouin` (GPL-3), `pyreadstat`/ReadStat
(GPL-происхождение), PyQt (GPL/коммерческая). Если захочется добавить
библиотеку — сначала проверьте лицензию: AGPL/GPL в закрытый продукт нельзя.

## Данные и персональные данные

- Демонстрационный набор (`src/winnow/samples.py`) генерируется кодом: это
  синтетические люди и ответы, не взятые из чужих исследований.
- Пользовательские наборы и ответы опросов принадлежат пользователю; программа
  их не публикует и не передаёт наружу. Импорт по ссылке — только по адресу,
  который ввёл сам человек, с защитой от внутренних адресов.
- В опросах по умолчанию нет ни аккаунта респондента, ни IP, ни адреса: в базе
  лежит случайный номер браузера. Перед публичным сервисом нужна политика
  обработки персональных данных — это отмечено в README в разделе «Перед
  публикацией».

## Модели ИИ и данные

Research Intelligence появился позже остального проекта; правила для него те
же, что и для расчётов:

* **ключ модели хранится только на сервере**, в окружении; в браузер и в ответы
  API он не попадает;
* **по умолчанию модели уходят схема, профиль и агрегаты**, а не строки данных;
  строки — только после явного разрешения на наборе;
* **бесплатные endpoint'ы могут обучаться на промптах** — для реальных данных с
  персональными сведениями нужен платный провайдер с политикой «не обучаться»
  или локальная модель;
* **ИИ не меняет данные и не выполняет код**: только чтение и вызов процедур;
* **числа берутся из расчёта** и сохраняются в `analysis_runs`; ответ модели
  ссылается на `run_id`, а интерфейс показывает таблицы из сохранённого
  результата, а не из текста.

## Товарные знаки и сравнения

SPSS и IBM — товарные знаки IBM. Проект называется **Winnow** и не использует
их в названии, логотипе и домене. Сравнение результатов с SPSS в документации —
фактическое («числа совпали с SPSS 27»), без указания на связь или одобрение.
Если планируете маркетинг, проверьте, что имя Winnow не занято в вашей
категории в стране регистрации.

## Как сохранять чистоту дальше

1. Новую функцию описывайте словами и формулами, а не «сделай как в окне X»;
   источник (статья, спецификация) фиксируйте в комментарии или в этом файле.
2. Не вставляйте код, найденный в интернете, без проверки лицензии; для
   небольших приёмов переписывайте по смыслу.
3. Сторонние библиотеки — только с разрешительной лицензией; копилефт — лишь
   если проект станет открытым под совместимой лицензией.
4. Тестовые данные генерируйте или берите с явной лицензией; чужие наборы из
   статей и учебников — нет.
5. Иконки, иллюстрации и шаблоны — свои или из наборов с лицензией, разрешающей
   коммерческое использование; храните ссылку на источник.
6. Заведите git-репозиторий: история коммитов — лучшее доказательство
   самостоятельной работы. Сейчас репозитория нет, это стоит сделать.

## Перед коммерческим релизом

- **Выбрать лицензию проекта.** Сейчас файла `LICENSE` нет. Для закрытой
  коммерческой версии подходят MIT или Apache-2.0 (или собственная
  проприетарная лицензия); для открытой — MIT/Apache-2.0, а если хотите, чтобы
  форки не закрывались, — GPL-3.0.
- Проверить условия LGPL для настольной сборки с Qt.
- Показать проект юристу: патенты на конкретные методы (в статистике редко, но
  бывает), товарный знак имени, условия площадок распространения.
- Проверить лицензии заново на момент релиза: они меняются.
