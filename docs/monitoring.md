# Мониторинг исследований

Сравнение двух волн исследования: базовая и текущая. Это ответ на пивот от
«ещё один сервис анкет» к **мониторингу и сравнению год за годом**.

## Что сравнивается

Автоматически находятся общие переменные двух наборов.

| Тип | Сравнение |
|---|---|
| количественная / порядковая | среднее, медиана, SD, разность средних, % изменения, 95 % ДИ, Welch t-test, Cohen's d |
| категориальная | доли категорий, процентные пункты, χ² однородности, V Крамера |

- Пропуски исключаются попарно.
- p-value считается по каждой переменной, q-value — Benjamini–Hochberg FDR.
- «Изменилось значимо» означает q < α (по умолчанию 0,05), а не причинный эффект.
- Порядковые переменные сравниваются как числа, но в отчёте стоит предупреждение:
  среднее для них — ориентир, важнее медиана и доли.

## Интерфейс

Раздел **«Мониторинг»** в боковом меню.

1. Выберите базовую и текущую волну (по умолчанию — самый старый и самый новый
   наборы по дате загрузки).
2. Нажмите «Сравнить волны».
3. Сводка покажет число общих/сравненных переменных и значимых изменений.
4. Таблица — значения по волнам, изменение, p, q и статус.
5. Для категориальных переменных кнопка «Все доли» раскрывает сдвиги по
   категориям в процентных пунктах.
6. Фильтр «Только значимые изменения» и поиск по переменной.

## API

`POST /api/monitoring/compare`

```json
{
  "baseline_id": 1,
  "current_id": 2,
  "variables": null,
  "alpha": 0.05
}
```

Ответ:

```json
{
  "baseline_id": 1,
  "current_id": 2,
  "report": {
    "baseline": {"name": "2024", "n_cases": 200},
    "current": {"name": "2025", "n_cases": 210},
    "variables": [],
    "summary": {},
    "methodology": {}
  }
}
```

Ошибки: одинаковые наборы — 422, чужой набор — 404, нет общих переменных — 422.

## Ограничения

- Это независимые выборки, а не панель одних и тех же респондентов.
- Сравниваются переменные с одинаковыми именами; если вопрос переименован,
  соответствие нужно задать вручную позже.
- Этот раздел — быстрое парное сравнение двух любых наборов. Для устойчивого
  мониторинга с тремя и более волнами есть отдельный раздел «Исследования»
  (`docs/studies.md`).
- Разные формулировки вопросов и шкал делают сравнение некорректным, даже если
  имена совпали.
