# Research Stress Test

Проверка устойчивости результата линейной регрессии: насколько коэффициенты,
значимость и выводы зависят от отдельных наблюдений, предпосылок, набора
переменных и случайной выборки. Включает Research Challenge — проверку
конкретной гипотезы. Это не доказательство причинности.

## Что делает MVP

- **Диагностика предпосылок:** VIF, Бреуш-Пеган, Уайт, Дарбин-Уотсон,
  Шапиро-Уилк, индекс обусловленности.
- **Влияние наблюдений:** Cook's Distance, leverage, стандартизованные остатки;
  сценарий без наиболее влиятельных точек.
- **Робастные стандартные ошибки:** HC0–HC3, сравнение p-value и доверительных
  интервалов с обычными SE.
- **Альтернативные спецификации:** удаление каждого предиктора, добавление
  контрольных переменных.
- **Чувствительность:** исключение выбросов по предикторам (1,5 IQR),
  доверительный уровень 90/95/99 %, а также исключение конкретных строк,
  выбранных пользователем (номера строк — как в таблице «Данные», 1-based).
- **История и экспорт:** список сохранённых прогонов набора, открытие прошлого
  отчёта без пересчёта, выгрузка в HTML, Word и Excel.
- **Bootstrap:** повторные выборки с возвращением, перцентильные интервалы,
  доля совпадения знака и доля p < α; гистограммы коэффициентов.
- **Сохранение:** каждый прогон сохраняется в `analysis_runs` с параметрами,
  seed и `dataset_revision`; `GET /api/stress-tests/{run_id}` открывает его.
- **Research Challenge:** гипотеза, фокус-предиктор, ожидаемое направление и
  контрольные переменные; проверка baseline, HC3, без влиятельных точек,
  с контролями, альтернативных спецификаций и Bootstrap. Статусы:
  «сохраняется», «ослабевает», «противоречит», «не проверено»; итог —
  «сохраняется», «частично», «противоречит» или «недостаточно данных».

## Где в интерфейсе

Отдельный раздел **«Устойчивость»** в боковом меню. Выберите набор, зависимую
переменную и предикторы. Режим «Авто» выбирает проверки по размеру выборки и
числу предикторов; ручной режим позволяет отметить нужные.

Отчёт состоит из разделов: **Обзор**, **Диагностика**, **Сравнение**,
**Чувствительность**, **Challenge** (если гипотеза задана), **Методология**.
Под формой — сохранённые прогоны набора; в шапке отчёта — кнопки Word / Excel /
HTML.

## API

`POST /api/datasets/{dataset_id}/stress-test`

```json
{
  "target": "income",
  "predictors": ["education", "age"],
  "checks": ["diagnostics", "influence", "robust", "specifications", "bootstrap"],
  "auto": false,
  "bootstrap": 500,
  "seed": 42,
  "confidence": 0.95,
  "alpha": 0.05,
  "add_controls": [],
  "exclude_rows": [3, 17, 20, 21, 22],
  "challenge": {
    "hypothesis": "образование положительно связано с доходом",
    "focal": "education",
    "direction": "positive",
    "controls": ["age"]
  }
}
```

Ответ:

```json
{
  "run_id": 12,
  "report": {
    "run_id": 12,
    "overview": {},
    "baseline": {},
    "diagnostics": {},
    "influence": {},
    "robust": {"HC0": [], "HC1": [], "HC2": [], "HC3": []},
    "scenarios": [],
    "bootstrap": {},
    "challenge": {
      "status": "supported",
      "summary": "...",
      "checks": []
    },
    "findings": [],
    "methodology": {}
  }
}
```

Ошибки валидации — 422 с понятным текстом. Чужой набор или прогон — 404.

`GET /api/datasets/{id}/stress-tests` — история прогонов.
`GET /api/stress-tests/{run_id}/export?format=html|docx|xlsx` — файл отчёта.

## Методика

- Модель — обычный OLS через существующий `winnow.stats.regression.fit_linear`.
- Робастная ковариация: `(X'X)^-1 X' diag(w) X (X'X)^-1`, где
  `w = e²` для HC0, `n/(n-p)·e²` для HC1, `e²/(1-h)` для HC2,
  `e²/(1-h)²` для HC3.
- Cook's Distance: `e²/(p·MSE) · h/(1-h)²`; порог `4/n`.
- Leverage: диагональ `X(X'X)^-1 X'`; порог `2p/n`.
- White: вспомогательная регрессия квадратов остатков на предикторы, их
  квадраты и произведения; `LM = n·R²`.
- Bootstrap: пары «наблюдение → строка» с возвращением, `n` строк в каждой
  выборке; перцентильные интервалы; фиксированный seed.
- Пропуски: **complete case** (строки с любым пропуском в модели исключаются).
  Импутации в MVP нет: она создаёт ложную точность.
- Веса случаев не используются; это ограничение MVP.

## Воспроизводимость

`params` прогона содержат target, predictors, checks, bootstrap, seed,
confidence, alpha, add_controls, exclude_rows и challenge (гипотеза, фокус,
направление, контроли). `payload` содержит сводку, гистограммы и таблицы для
экспорта; `dataset_revision` фиксирует версию файла на момент расчёта.

## Ограничения

- Только линейная регрессия; логистическая, ANOVA, корреляции и факторный
  анализ — позже.
- Нет импутации пропусков и весов.
- Произвольные строки исключаются по номерам из таблицы «Данные»; при активном
  фильтре нумерация относится к отфильтрованному набору.
- Множество проверок не заменяет пререгистрацию гипотезы: отчёт показывает
  устойчивость, а не «доказывает» связь.
- Research Challenge сравнивает направление и значимость фокус-коэффициента;
  он не проверяет всю причинную модель и не заменяет содержательную теорию.
- R² и p-value зависят от спецификации; Stress Test показывает это, а не
  выбирает «лучшую» модель за пользователя.
