# Эталоны SPSS для взвешенных процедур

Источник: вывод SPSS Statistics (`Вывод1.spv`), данные `docs/weights-reference.csv`,
`WEIGHT BY w`. Сумма весов = 22, случаев = 12.

Главный вывод: **SPSS веса применяет** в UNIANOVA, REGRESSION и CORRELATIONS —
предупреждений в примечаниях нет, а N в таблицах равен 22 (сумме весов), а не 12.
Значит предупреждение «веса не учитываются» в Winnow — временное ограничение,
а не поведение SPSS. После реализации формул его надо снять для этих процедур.

## Формулы, подтверждённые арифметикой

Проверено на группе 1 (группа, вес, значения y: (10, 2), (12, 1), (11, 3), (13, 1)):

**Взвешенное среднее** — сумма w·y, делённая на сумму w:

```
(2·10 + 1·12 + 3·11 + 1·13) / 7 = 78 / 7 = 11,1429 → 11,14 ✓
```

**Эффективное N группы** — сумма весов (7), а не число случаев (4) ✓

**Взвешенное стандартное отклонение** — с знаменателем (сумма весов − 1):

```
SS = 2·1,1429² + 1·0,8571² + 3·0,1429² + 1·1,8571² = 6,856
var = 6,856 / (7 − 1) = 1,1427  →  SD = 1,069 ✓
```

**Межгрупповая сумма квадратов** — Σ W_j (ȳ_j − ȳ)², где W_j — сумма весов группы:

```
7·(11,1429 − 20,4545)² + 8·(20,125 − 20,4545)² + 7·(30,1429 − 20,4545)²
= 606,97 + 0,87 + 657,03 = 1264,87   (SPSS: 1264,865 — совпадение с точностью округления) ✓
```

**Степени свободы** — по эффективным N: ошибка 22 − 3 = 19, всего 22 ✓

**Общий разброс регрессии** — тот же 1295,455, что «скорректированный итог» в ANOVA,
значит WLS считается по тем же взвешенным SS ✓
