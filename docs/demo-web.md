# Показ веб-версии Winnow: план на 7 минут

## За 10 минут до пары

1. Запустить сервер — окно **не закрывать**:
   ```
   web\run.cmd
   ```
2. Открыть приложение: `web\open.cmd` или вручную `http://127.0.0.1:8000/`
3. **Ctrl+Shift+R** — чтобы не показать старую сборку из кэша.
4. Войти своим аккаунтом заранее и проверить, что наборы на месте.
5. Убедиться, что под рукой файл `E:\Down\67.csv\67.csv` (для загрузки «с нуля»).
6. Если нужен доступ с ноутбука преподавателя — см. раздел в конце.

## Сценарий показа

### 1. Вход и данные (1 мин)
- Открыть главную: «это платформа для сбора и анализа данных», два пути —
  «Создать опрос» и «Исследовать данные».
- Нажать **«Исследовать данные»** (или «Войти» справа) → экран входа:
  «регистрация по приглашению, первый пользователь без кода».
- Войти. Слева — список наборов, справа — рабочая область.
- Нажать **«Загрузить файл»** → `67.csv`. Появится «213 случаев · 21 переменная».
- Вкладка **«Переменные»**: метки, уровни измерения, пропуски — «это паспорт данных, как в SPSS».

### 2. Подсказки советчика (2 мин) — главное отличие от SPSS
- Вкладка **«Что можно сделать»**. Сказать: «SPSS требует знать, какой тест выбрать.
  Здесь программа сама смотрит данные и предлагает исследования с обоснованием».
- Показать карточку «Сопоставить две категории»: вопрос, «почему», предупреждение о малых частотах.
- Нажать **«Выполнить»**. Появится отчёт: блок **«Простыми словами»** → таблицы.
- Прочитать вывод вслух: «Признаки связаны: p = 0,030, V Крамера = 0,213 — умеренная связь, 213 случаев».
- Сказать: «Числа те же, что в SPSS; сверены по эталонам, 434 теста движка».

### 3. Выгрузка (1 мин)
- Кнопки **Word / Excel / HTML** в шапке отчёта → скачать Word → открыть:
  «готовый отчёт для диплома, не нужно перепечатывать таблицы».

### 4. Качество данных (1 мин)
- Вкладка **«Качество»** → «Проверить данные». Появятся пропуски, дубликаты,
  выбросы, дисбаланс групп и корреляции — с числами.
- Выбрать зависимую переменную (например, «удовлетворённость жизнью») →
  «Проверить модель»: добавятся VIF, Бреуш-Пеган, Дарбин-Уотсон и влияние точек.
- Сказать: «Это не ИИ: проверки считает ядро. Агент потом опирается на эти числа,
  а не на общие слова “данные грязные”».

### 5. Графики (1 мин)
- Нажать **☆** внизу панели (экспертный режим) — появятся «Процедуры» и «Графики».
- «Графики» → «Гистограмма» → переменная «возраст» → «Построить график».
- Показать переключение темы кнопкой **☀ / ☾** внизу панели: график и отчёт перестраиваются сами.

### 6. Ручной выбор процедур (1 мин)
- **«Процедуры»** → «Таблицы сопряжённости» → строка «социальный статус», столбцы «пол» и «благосостояние» → «Выполнить».
- Показать: две пары разделены заголовками, нумерация таблиц непрерывная.
- Показать **«Считать по группам»** → «пол»: отчёт по каждой группе отдельно
  с выводами, подписанными группой.

### 7. Правка данных и выгрузка набора (30 с)
- Вкладка **«Данные»** → изменить ячейку → «Сохранить изменения» → обновить страницу: значение сохранилось.
- **«Скачать: SAV»** → «файл открывается в SPSS вместе с правками».

## Если спросят

| Вопрос | Ответ |
|---|---|
| Чем отличается от SPSS? | Тот же расчёт, но подсказки вместо выбора теста, объяснение простыми словами и выгрузка в Word |
| Где считается статистика? | В общем движке на Python (11,7 тыс. строк), он же в настольной версии; веб только доставляет |
| Проверено ли? | 434 теста движка, 119 тестов API, ИИ и качества, эталонные числа сверены |
| А если интернет пропадёт? | Работает локально, интернет не нужен |
| Где хостить? | Планируется VPS + PostgreSQL; сейчас SQLite для разработки |
| А собрать данные? | Да: раздел **«Опросы»** — конструктор, ссылка `/s/…` без входа, ответы в базе; кнопка «Исследовать в Winnow» превращает их в набор |
| А с ИИ? | Да: раздел **«Исследование AI»** — вопрос словами, агент подбирает метод, запускает реальный расчёт и объясняет; числа можно открыть в карточке расчёта |

## Доступ с ноутбука преподавателя (если есть Wi-Fi)

В окне сервера:
```powershell
$env:WINNOW_HOST = "0.0.0.0"
$env:WINNOW_INVITE_ONLY = "0"     # чтобы преподаватель мог зарегистрироваться сам
web\run.cmd
```
Узнать свой адрес: `ipconfig` → «IPv4-адрес» (например `192.168.1.42`).
Преподаватель открывает `http://192.168.1.42:8000/`.

Windows спросит про доступ в сеть — разрешить для частных сетей.
Если не открывается — скорее всего блокирует брандмауэр или Wi-Fi изолирует клиентов.

## Если что-то сломалось на показе

1. **Не перезапускать сервер сразу** — сначала **Ctrl+Shift+R**.
2. Проверить серверную часть: `web\check.cmd` — покажет, что именно отвалилось.
3. Открыть второй набор (`учебный (2).sav` или `.xlsx`) — если он работает, показать на нём.
4. Держать под рукой скриншоты: `docs/screenshots/`.
