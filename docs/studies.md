# Исследования, волны и тренды

Полноценный мониторинг: исследование объединяет несколько волн (наборов данных),
а не только две выбранные вкладки.

## Модель

```
Study (исследование)
  ├── StudyWave: 2022 → dataset_id
  ├── StudyWave: 2023 → dataset_id
  └── StudyWave: 2024 → dataset_id
```

- `Study`: владелец, название, описание, дата создания.
- `StudyWave`: ссылка на набор, подпись, год (необязательно), позиция.
- Один и тот же набор нельзя добавить в исследование дважды.
- Удаление исследования удаляет его волны; наборы данных остаются.

## API

| Метод | Что делает |
|---|---|
| `GET /api/studies` | список исследований с числом волн |
| `POST /api/studies` | создать исследование |
| `GET /api/studies/{id}` | исследование и его волны |
| `POST /api/studies/{id}/waves` | добавить набор как волну |
| `DELETE /api/studies/{id}/waves/{wave_id}` | убрать волну |
| `DELETE /api/studies/{id}` | удалить исследование |
| `POST /api/studies/{id}/trends` | построить тренды по волнам |

## Тренды

`src/winnow/analysis/trends.py`:

- общие переменные **всех** волн;
- количественные: среднее по волнам, линейный тренд (OLS), наклон за год
  (если годы заданы) или за волну, R², изменение first→last, p;
- категориальные: доли по волнам, χ² однородности, V Крамера, максимальный
  сдвиг в процентных пунктах;
- Benjamini–Hochberg FDR по переменным;
- две волны допустимы, но p тренда появляется при трёх и более;
- волны — независимые выборки; тренд не доказывает причинность.

## Интерфейс

Раздел **«Исследования»** в боковом меню:

1. создать исследование (можно несколько);
2. добавить волны из загруженных наборов, задать подпись и год;
3. увидеть таймлайн волн;
4. таблицу трендов со sparkline, p/q и статусом;
5. методологию и предупреждения.

Раздел **«Мониторинг»** остаётся для быстрого парного сравнения двух любых
наборов без создания исследования.

## Ограничения

- Нет ручного сопоставления переименованных вопросов: общие переменные
  определяются по имени.
- Нет взвешивания волн и поправки на состав выборки.
- Нет доверительных полос вокруг тренда и прогноза.
- Нет сохранения отдельного «отчёта мониторинга» как файла.
- Волны — независимые выборки; выводы о причинах не поддерживаются.
